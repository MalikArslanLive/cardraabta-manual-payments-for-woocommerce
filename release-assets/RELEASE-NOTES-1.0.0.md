## CardRaabta Manual Payments for WooCommerce 1.0.0

Accept manual bank, wallet and Raast payments in PKR. Customers submit payment proof; store managers independently verify received funds.

- Classic Checkout, Checkout Blocks and HPOS support.
- Configurable proof fields, replacement history, payment review and CSV exports.
- Encrypted private screenshots, notifications and manager-only email logs.

**Requirements:** WordPress 6.5+, WooCommerce 8.3+, PHP 8.1+, OpenSSL/Fileinfo and MySQL/MariaDB named locks.

**Install:** Download `cardraabta-manual-payments-for-woocommerce-v1.0.0.zip` from Assets below, then upload it through WordPress Plugins. GitHub source archives include development files.

**Hosting:** Nginx requires the documented private-upload denial rule; Apache/OpenLiteSpeed must load the supplied access rules. IIS needs URL Authorization and delegated authorization rules. Back up the database, evidence files and encryption key together.
