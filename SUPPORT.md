# Support

Start with [store setup and troubleshooting](docs/SETUP.md) or the [hosting guide](docs/HOSTING-SETUP.md) for upload, cache or server questions.

For general help or a reproducible bug, [open a GitHub issue](https://github.com/MalikArslanLive/cardraabta-manual-payments-for-woocommerce/issues/new/choose). Include plugin, WordPress, WooCommerce and PHP versions, checkout type, the steps you tried, and what you expected to happen. Use test data and redact logs. Keep customer information, receiving account details, proof screenshots, transaction CSVs, credentials and private order links out of public issues.

For a suspected vulnerability, follow the [private reporting instructions](SECURITY.md).
